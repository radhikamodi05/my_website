Selected work at Winpra AI

LLM fine-tuning and post-training

I fine-tuned dense and mixture-of-experts models for structured reasoning, tool use, and code and configuration generation. My work covered the training data, GPU runs, regression evaluation, and deployment.

Training data and alignment

Built synthetic instruction datasets, preference pairs, hard negatives, and reward signals. Used supervised fine-tuning (SFT), direct preference optimization (DPO), and group relative policy optimization (GRPO) for domain tasks.

Multi-GPU training

Used QLoRA and PyTorch FSDP2 to run 12B–35B models across self-hosted RTX 5090 GPUs. Debugged memory pressure, distributed failures, and model-specific attention compatibility when increasing context length.

Evaluation and serving

Combined task-specific evaluations with general regression tests to compare checkpoints and adapters before release. Deployed models with vLLM and llama.cpp, using quantization and dynamic LoRA loading to serve multiple specialized behaviors.
